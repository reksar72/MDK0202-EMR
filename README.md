# МДК 02.02 — программы к ПР 3, 4, 6 и 7

Шваб Роберт Эдуардович · И13_24_11 · вариант 2 из нового сборника: АИС «Электронная медицинская карта».

## Требования
.NET 8 SDK, Visual Studio 2022 17.8 или новее. WPF-клиент запускается на Windows 10/11. Сборка UI не предназначена для Windows 7. API, импорт и тесты могут выполняться отдельно на поддерживаемой .NET системе.

## Какая программа к какой работе
| Работа | Проект запуска | Назначение |
|---|---|---|
| ПР 3 | src/AIS.MappingCli | JSON реестра → Patient → SQLite |
| ПР 4 | src/AIS.Gateway | JSON-контракт, проверки доступа, шифрованный аудит |
| ПР 6 | src/AIS.Gateway + src/AIS.Desktop | API и WPF-клиент MVVM |
| ПР 7 | Emr.sln + tests/AIS.Tests | Модульная структура и проверки зависимостей |

Для ПР 1, 2, 5, 8 и 9 отдельная прикладная программа не требуется; результаты — документы, диаграммы и файлы Git.

## Сборка
Открыть Emr.sln в Visual Studio или выполнить из этой папки:
```sh
dotnet restore Emr.sln
dotnet build Emr.sln
dotnet run --project tests/AIS.Tests -- verification
```
AIS.Tests — консольный запускатель проверок, не xUnit; использовать dotnet run, не dotnet test.

## ПР 3 — импорт
```sh
dotnet run --project src/AIS.MappingCli -- data/source-patient.json verification
```
Выход: mapped-patient.json и локальная mapping-demo.db. Повторный импорт той же версии возвращает DUPLICATE. Для нового UUID можно передать третий аргумент. Исходная дата берётся из учебного сценария на 05.11.2026.

## ПР 4 — API
```sh
dotnet run --project src/AIS.Gateway -- --demo
```
Открыть http://127.0.0.1:5274. В меню доступны ПР 3 (Data Mapping), ПР 4 (доступ) и ПР 6 (проверка ViewModel). Это работающий проверочный интерфейс на C#, не изображение окна WPF.

Сервер создаёт временную SQLite с одним вымышленным пациентом, случайный ключ AES-256-GCM и учебные opaque-токены. Doctor token печатается в консоли только этого запуска. Файлы и ключ удаляются после остановки; они не предназначены для архива реальных медицинских журналов. Служебные секреты не включены в архив.

## ПР 6 — WPF MVVM
1. Оставить API запущенным.
2. Открыть второй терминал в этой папке: `dotnet run --project src/AIS.Desktop`.
3. Оставить адрес http://127.0.0.1:5274 и вставить Doctor token из консоли API в поле токена.
4. Нажать «Открыть клиент», затем «Загрузить карту».
5. Должны появиться имя «Пациент Учебный Один», дата 1990-02-14 и статус «Карта загружена».
6. Ввести неверный UUID: старые данные очищаются, появляется сообщение об ошибке.

Скомпилированы все 8 C#-проектов; выполнены API-, mapping- и ViewModel-проверки. Запуск WPF-клиента на Windows и успешная загрузка карты подтверждены снимком docs/screenshots/PR06_WPF_Loaded.png. Это снимок настоящего окна приложения; полный набор автоматических проверок выполнялся отдельно от оконного интерфейса.

## Границы доступа
Врач и медсестра работают только с назначенной картой. Admin не получает право чтения медицинской записи автоматически. Роль и actorId берутся из серверного токена, а не из JSON запроса. Номер полиса не входит в summary. Назначение рабочей станции — проверяемый идентификатор запроса, а не замена аутентификации устройства.
Внешние IdP и реестр в C4 — архитектурные контуры; фактическое подключение к ним не выполнялось. Для рабочего внедрения нужны доверенный IdP, TLS, управляемые ключи и отдельная политика эксплуатации; программа содержит только учебный локальный запуск.
